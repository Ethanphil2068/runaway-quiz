# runaway-quiz 😈

A 2-question prank quiz to send to your friends.

1. **What is your name?** — type your name.
2. **What gender are you?** — pick A (Straight) or B (Lesbian/Gay).
   - Option A *runs away* from your cursor/finger (smooth physics, never teleports).
   - After 15 escapes it gives up and becomes clickable for a surprise ending.
   - Option B is always clickable → confetti + official certificate with your name.

Single static file, no dependencies. Just open `index.html` or serve the folder.

## Run locally

```
start index.html
```

## Deploy

Live on GitHub Pages. To redeploy after changes:

```
git add . && git commit -m "update" && git push
```
